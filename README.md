# Repositorio de estudio y experimentación

Repositorio personal de estudio, prácticas y experimentación. El contenido 
se organiza por áreas independientes y se actualiza conforme avanza el 
aprendizaje.

## Contenido

- Apuntes y notas de estudio
- Ejercicios y prácticas
- Experimentos y pruebas
- proyectos no consolidados
- Referencias y material de consulta
- Código desarrollado durante el aprendizaje

> La organización y el contenido pueden cambiar.

## Organización

Cada área mantiene su propia estructura según [DOMER](#). Puede tener 
mínimas variaciones en los criterios de organización según su propósito.

No todas las secciones tienen el mismo nivel de desarrollo ni siguen 
necesariamente una progresión lineal.

## Estado

El contenido se encuentra en desarrollo continuo.
